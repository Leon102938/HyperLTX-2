# Visual Spec

Diese Datei sammelt spaeter textliche Beschreibungen von Screenshots, Referenzbildern und Zielzustaenden fuer die finale Panel-Struktur.

Codex darf sich nicht nur auf Bilddateien verlassen. Jede visuelle Referenz muss hier oder in einer direkt verlinkten Spezifikation textlich beschrieben werden, damit Layout, Hierarchie, Abstaende, Kontrast, Bedienbarkeit und Zweck nachvollziehbar bleiben.

## Beschreibungsschema fuer Screenshots und Bilder

Fuer jede Referenz erfassen:

- Quelle: Dateiname, Screenshot-Link oder kurzer Kontext
- Relevanter Bereich: welches Panel oder welcher UI-Zustand gemeint ist
- Layout: Spalten, Reihenfolge, Groessenverhaeltnisse, feste oder flexible Bereiche
- Hierarchie: wichtigste Elemente, sekundaere Elemente, Hintergrundinformationen
- Interaktion: Buttons, Tabs, Auswahlfelder, Drag/Drop, Listen, Menues
- Zustand: empty, loading, error, partially configured, ready, active
- Visuelle Regeln: Farben, Typografie, Spacing, Borders, Dichte
- Uebernahmeentscheidung: uebernehmen, anpassen oder verwerfen
