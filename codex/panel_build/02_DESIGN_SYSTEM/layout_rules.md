# Layout Rules

Diese Regeln fuehren den spaeteren Panel-Build beim Layout.

## Grundstruktur

- Panels folgen der Reihenfolge `01` bis `09`.
- Die aktive Pipeline bleibt sichtbar oder schnell erreichbar.
- Primaere Arbeitsbereiche duerfen nicht von dekorativen Elementen verdraengt werden.
- Inhalt muss bei Desktop- und kleineren Viewports lesbar bleiben.

## Panel-Dichte

- Operative Panels sollen scanbar und kompakt sein.
- Wiederkehrende Controls muessen an konsistenten Positionen stehen.
- Lange Inhalte brauchen klare Scroll-Bereiche.
- Kein Text darf Buttons, Inputs oder Nachbarelemente ueberlappen.

## Navigationslogik

- Der User soll erkennen, wo er im Workflow steht.
- Abhaengigkeiten zwischen Panels muessen sichtbar sein.
- Gesperrte oder noch nicht konfigurierte Panels brauchen begruendete Empty States.

## Responsive Regeln

- Kritische Aktionen bleiben erreichbar.
- Panels duerfen stapeln, wenn Breite fehlt.
- Feste Formate wie Listen, Grids und Workspaces brauchen stabile Dimensionen.
