# Main Goal

Ziel dieses Aufgabenpakets ist es, die finale Panel-Struktur fuer den Image-, Keyframe-, Mapping- und Compiler-Workflow der Content Maschine bis Panel `09_active_workspace` vorzubereiten.

Der spaetere Build soll keine komplette Architektur neu erfinden. Bestehende Panels, vorhandene Zustandsmodelle, bestehende Komponenten und bereits funktionierende Workflows muessen zuerst gelesen und respektiert werden.

Der Fokus liegt auf:

- finalisieren: vorhandene Panel-Ideen in eine klare finale Reihenfolge bringen
- ausbessern: sichtbare Luecken, unklare States und inkonsistente UI-Regeln korrigieren
- verbinden: Pipeline-Auswahl, Mode, Style, Hook, Models, Mapping, Keyframes, Compiler und aktiven Workspace logisch zusammenfuehren
- testen: Sichtbarkeit, Bedienbarkeit, State-Logik und Build-Stabilitaet pruefen

Nicht-Ziele:

- kein kompletter Architekturumbau
- keine pauschalen Refactors ohne konkreten Panel-Nutzen
- keine neuen UI-Bibliotheken ohne zwingenden Grund
- keine Dummy-UI, die spaeter nicht mit echtem Verhalten verbunden werden soll

Der spaetere Codex-Durchlauf soll diese Datei zuerst lesen, danach `BUILD_RULES.md`, danach die Panel-Spezifikationen und erst dann Code anfassen.
