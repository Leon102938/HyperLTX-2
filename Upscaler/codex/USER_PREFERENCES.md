# USER_PREFERENCES.md

## Kommunikationsstil
- direkt
- klar
- kompakt
- wenig Blabla
- keine geschminkte Unsicherheit

## Arbeitsstil
- pragmatisch
- modular
- in Stufen baubar
- zuerst brauchbarer Kern, dann Ausbau
- keine unnoetige Theorie

## Architekturpraeferenzen
- RunPod ist die Zielumgebung
- Fokus auf `/workspace`
- n8n bleibt spaeter die aeussere Zentrale
- kein ComfyUI als Pflichtsystem
- zuerst Agent-Core, spaeter API, danach n8n
- vorhandene lokale Modelle, Skripte und Services sollen genutzt werden koennen

## Negative Praeferenzen
- kein fluffiger Fake-Plan
- keine nutzlose Agentik
- kein blindes Nachbauen fremder Repos
- keine GUI in der Kernphase
- keine ueberkomplizierte Phase-1-Architektur

## Pflegehinweis
Nur dauerhafte Praeferenzen eintragen.
