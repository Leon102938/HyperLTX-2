# SYSTEM_EVOLUTION.md

## Zweck
Regelt, wie das Projektgedaechtnis verbessert werden darf.

## Leitlinie
- Das System soll nuetzlicher werden, nicht nur groesser.
- Neue Dateien nur, wenn sie wiederkehrende Klarheit schaffen.
- Historisch relevante Entscheidungen nicht spurlos ueberschreiben.

## Erlaubt
- bestehende Memory-Dateien schaerfen
- neue Audit- oder Bereichsdokus anlegen, wenn sie echten Nutzen bringen
- wiederkehrende Stolperfallen dokumentieren
- Dopplungen reduzieren

## Nicht erlaubt
- Mission eigenmaechtig aendern
- Nutzerpraeferenzen verwischen
- bestaetigte Architekturgrenzen still ersetzen
- Doku aufblasen, nur um Vollstaendigkeit vorzutaueschen
